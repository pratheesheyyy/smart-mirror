01 — Overview

Project Overview

The Smart Mirror is an IoT-based embedded system that integrates traditional mirror functionality with real-time computing and internet capabilities. Built on a Raspberry Pi 3 running Raspbian Linux, the device overlays a 19-inch LCD display behind a one-way reflective mirror film, enabling users to access live information hands-free during their daily routine.

The project addresses a practical problem: individuals lose time during morning routines switching between a mirror and their phones or tablets to check weather, news, and schedules. The Smart Mirror eliminates this friction by unobtrusively displaying relevant data on the sides and corners of the reflective surface, keeping the central reflection clear for use.

Objective: Design and implement an interactive smart mirror system that provides real-time information — time, date, weather, news, and notifications — through voice commands and facial recognition, with minimal user effort.

03 — Hardware

Hardware Architecture

The physical build integrates off-the-shelf components into an aesthetically clean, wall-mountable form factor. Key design constraints included weight, heat dissipation, mirror-to-screen alignment, and moisture resistance for bathroom environments.

Component Specification / Role
Raspberry Pi 3 Central processing unit — 1.2 GHz quad-core ARM Cortex-A53, 1 GB RAM, running Raspbian Linux
LCD Display 19-inch panel providing the information overlay; anti-glare, high-resolution, energy-efficient
One-Way Mirror Film Maintains reflectivity when display is off; allows display content to show through when on
Microphone USB microphone for voice command capture — wide frequency response, moisture-resistant
SD Card (16 GB) Storage for Raspbian OS, application code, and user profile data
Power Supply 5V micro-USB regulated supply integrated into the mirror frame
Mirror Frame Custom wooden frame housing all components with cable management
04 — Software

Software Architecture

The software stack runs entirely on the Raspberry Pi under Raspbian Linux. The system is modular: each widget (clock, weather, news, calendar) is an independent, hot-swappable module. The Raspberry Pi connects to the internet over Wi-Fi to fetch live data from external APIs.

Technologies Used

  • Python — core application logic, API integration, voice recognition pipeline
  • MagicMirror² Framework — modular UI rendered in a fullscreen Chromium window
  • Electron / Node.js — widget runtime and inter-process communication
  • OpenCV — facial recognition and presence detection via camera feed
  • Google Assistant API — natural language voice command processing

External APIs

  • OpenWeatherMap API — real-time weather and forecast data
  • News API — live headline and article feeds
  • Google Calendar API — calendar events and reminders
  • Wi-Fi Module (built-in RPi 3) — seamless internet connectivity
Key Challenge: Achieving reliable voice recognition under ambient environmental noise. The microphone sensitivity and voice recognition package were iteratively calibrated; overclocking the Raspberry Pi processor resolved response latency issues encountered during testing.
